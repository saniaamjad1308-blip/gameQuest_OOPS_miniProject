# 🎮 GameQuest — Gaming Tournament and Player Ranking System

## 📌 About the Project

**GameQuest** is a C++ mini-project designed to manage gaming tournament players, record match scores, and rank players through a leaderboard. It demonstrates important Object-Oriented Programming (OOP) concepts through a practical gaming-themed application.

The system supports different player types, validates scores, handles errors using custom exceptions, and saves tournament results to files.

## ✨ Features

- **Player Management:** Add and manage tournament players.
- **Multiple Player Types:** Supports Casual and Professional players.
- **Match Scoring:** Record and validate player scores.
- **Leaderboard:** Display players according to their performance.
- **Custom Exception Handling:** Handles duplicate players, invalid scores, and missing players.
- **Operator Overloading:** Demonstrates custom behavior for player comparison and operations.
- **Polymorphism:** Uses an abstract base class and derived player classes.
- **File Handling:** Saves and loads tournament results using CSV and text files.
- **Smart Pointers:** Uses `shared_ptr` for player object management.

## ▶️ How to Run

### Prerequisites
Install a C++ compiler that supports C++17, such as GCC.

### Compile the program

```bash
g++ -std=c++17 -Wall -Wextra -o gamequest gamequest.cpp
```

### Run the program

On Windows:

```bash
gamequest.exe
```

On Linux/macOS:

```bash
./gamequest
```
